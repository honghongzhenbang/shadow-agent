# ADR-0017 图谱路由与有界一级证据检索

- 状态：接受
- 日期：2026-08-29
- 决策者：项目用户、Codex
- 关联契约：INV-03、INV-04、INV-06、INV-24、INV-26、INV-27、INV-29、INV-46、INV-50、INV-55、INV-56、INV-60
- 取代：无

## 背景

知识图谱能够定位人员、项目、会话和候选事实，但精确会话归因、提交边界、原始数值和未知边界仍需回到 Evidence Log。原有上下文工具只返回少量图谱证据摘要；扩大 Codex turns 或全局模糊搜索会引入同名会话、重复仓库、历史 Agent 结论和高体量工具日志，并增加上下文与查询成本。

隔离金标准首轮 6 条均未完全通过。主要失效包括只看到同名 fork 而未沿父链、中文组合词全部命中导致漏召回、长证据只截取开头、相近人员和相近故障被合并。首版证据工具修复准确性后，真实库又暴露无范围多词 `LIKE` 可达数秒、提交哈希没有使用结构化标识、操作日志可能形成自引用噪声等问题。

## 决定

1. 图谱继续作为长期事实与认知路由层，不复制原始会话、文档或代码正文。
2. 新增只读 `shadow_evidence_search` 作为统一一级证据展开工具。结构范围优先级为 evidence id / `externalId`、thread/conversation、project/source/time、关键词回退。
3. 默认仅查询人类可读和权威主证据。Codex tool call/output/result 与 patch result 保留为可显式选择的操作证据，不进入普通默认搜索。
4. 提交 SHA 等外部标识通过 `(kind, external_id)` 索引查询；连续中文可做有限词段和双字组合回退。结果始终受条数与 UTF-8 字节预算限制。
5. 返回模型前再次脱敏标题、正文、来源定位和查询回显。所有检索正文均标记为不可信数据，不能覆盖系统规则、授权或任务状态。
6. 生成摘要、Agent 旧回答、任务结果和图谱派生结论不得作为默认一级证据。冲突与缺失必须保留，不得用最新或最相似材料自动覆盖。
7. Codex 会话存在 fork/parent 时沿父链核对实际工具和文件证据；同一 Git SHA 出现在多个仓库只说明对象可见，不能单独证明开发目录。

## 备选方案

- **把更多历史直接放进主会话**：增加 Token、同名噪声和自引用，不解决证据等级，驳回。
- **为每类问题开发专用检索器**：短期准确但会形成版本、人员、飞书等多套上层知识库，驳回。
- **为全部 Evidence 建立中文 trigram 全文索引**：全局子串搜索更快，但当前约 60 万条记录会显著增加数据库体积和迁移成本；在结构化范围查询已低于模型耗时两个数量级的情况下暂不采用。
- **继续对全表执行多词 LIKE 排序**：实现简单但无范围查询可达数秒，并把工具日志噪声排在前面，驳回。

## 影响

- 插件新增一个兼容工具和一个 Evidence 外部标识索引，项目实现版本升至 V4.12.0。
- 常见飞书范围检索在当前真实库上约 60 至 175 ms；提交 `externalId` 中位数约 23 ms。无范围关键词回退仍可能达到约 3 秒，因此只作为最后手段，不构成常规主链。
- Agent 回答必须区分图谱候选、一级证据和自身推断；自动关键词评分继续只作辅助，人工事实核对或结构化评分才可宣布通过。

## 数据迁移

数据库下次以可写模式初始化时使用 `CREATE INDEX IF NOT EXISTS evidence_kind_external_id_idx ON evidence(kind, external_id)` 增量建立索引。Evidence 内容、ID、图谱、任务和会话无需改写；旧运行时在索引建立前仍可正确查询，只是精确外部标识速度较慢。

## 回退方案

移除工具注册和工作区说明即可停止模型调用；新增索引可保留且不改变数据语义，也可在停机维护时删除。回退不需要恢复 Evidence 或图谱数据。

## 验证

- 单元测试覆盖无空格中文、通配符转义、来源/项目/会话/时间范围、字节预算、只读、凭据脱敏、操作日志显式选择和未知来源拒绝。
- 私有隔离评测覆盖 Codex 会话与提交归因、飞书职责、相近故障、数值保真、未知边界、接口影响和重复仓库溯源。
- 真实库基准分别报告结构化 ID、飞书范围查询和无范围回退，不把模型推理时间算作数据库检索时间。
- 隔离 OpenClaw 无 Workboard、channel、hook、提醒和外发能力；评测完成后默认删除数据库快照与隔离 state。
