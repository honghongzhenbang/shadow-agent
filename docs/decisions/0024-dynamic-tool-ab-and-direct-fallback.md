# ADR-0024 动态工具 A/B 与 direct 生产回退

- 状态：接受
- 日期：2026-08-31
- 决策者：项目维护者
- 关联契约：INV-53、INV-55、INV-66、INV-67
- 取代：ADR-0023
- 适用版本：V4.18.1+

## 背景

ADR-0023 根据当前 OpenClaw 官方默认值和一次成功的只读工具冒烟，把 Codex 动态工具从 `direct` 改为 `searchable`。该冒烟只能证明某一全新线程曾成功搜索 `shadow_context_status`，不能回答多种自然语言任务的稳定命中率。用户要求进一步验证响应性能、回答质量和找错/找不到工具风险。

## 决定

1. 使用同一 `gpt-5.6-sol`、低思考等级、全新隔离会话和六个只读用例比较 `direct` 与 `searchable`。用例覆盖明确工具名、自然语言状态、工作简况、提醒、持续追踪和 Workboard。
2. 成功必须同时满足：目标工具实际调用一次、没有额外业务工具、回复标记正确。明确不可用、无回复超时和误选分别计数，不用文字答案替代工具证据。
3. 初轮 `direct` 完成 5/6，唯一 Workboard 超时在全新会话复测成功；所有成功轮都只调用目标工具。`searchable` 完成 2/6，三轮明确回复工具不可用，一轮 180 秒无回复；没有误选其他工具。
4. 当前生产恢复 `codexDynamicToolsLoading: direct`。可靠性优先于成功样本中约 46% 的共同用例时延下降和约 6% 的 Token 下降。
5. 不修改 OpenClaw 底层硬编码来制造未受支持的混合模式。未来只有在官方提供受支持的分层装载，或 `searchable` 在代表性多工具盲测中达到不低于 `direct` 的完成率时重新评估。

## 备选方案

- 保留纯 `searchable` 并依赖重试：拒绝。工具不可见会把普通任务变成额外模型轮和等待，抵消上下文收益并降低主动推进可靠性。
- 根据提示词固定写工具名：拒绝。明确写出 `shadow_context_status` 的用例仍出现工具不可用，不能解决线程级搜索能力缺失。
- 修改 OpenClaw 源码增加项目专用常驻工具表：拒绝。当前官方配置只有全局 `direct/searchable` 和排除项，维护私有补丁的风险高于已测得收益。
- 删除低频工具缩小 `direct` 上下文：暂不采用。哪些工具低频需要更长时间的生产指标，不能根据一次基准削能力。

## 影响

- 生产任务继续获得确定的工具可见性，不会因为延迟工具搜索偶发不可用而静默跳过。
- 全新成功轮的固定上下文和平均时延高于 `searchable` 成功样本；继续通过稳定会话、缓存、提示预算和运行指标控制成本。
- 风险主要表现为“找不到工具”，本次没有观察到“找错工具”，两类指标仍须分开。

## 数据迁移

无需迁移 Evidence、图谱、Workboard 或会话。应用版本化运行模板并重启 Gateway 即可。A/B 原始 JSON 保存在 Git 忽略的 `runtime/evaluations/dynamic-tool-loading/`，仓库只保存匿名聚合结论。

## 回退方案

若未来受支持的 `searchable` 实现通过同一基准，可修订契约和 ADR 后切换；不得只修改运行时 JSON。切换失败时恢复 `direct`、应用模板并重启 Gateway，不删除会话或业务数据。

## 验证

- `direct` 原始证据：`2026-08-31T02-14-42-872Z-direct.json`；Workboard 复测：`2026-08-31T02-27-09-234Z-direct.json`。
- `searchable` 原始证据：`2026-08-31T02-22-35-068Z-searchable.json`。
- OpenClaw 2026.8.1 + 600 秒隔离预算回归：`status_exact`、`vocabulary_long_tail` 2/2 通过，原 Workboard 用例单独复测通过；三轮均无工具不可用、误选或超时。原始 JSON 位于 Git 忽略的本机评测目录。
- 运行主项目、插件、Gateway 集成和契约测试，确认生产模板、部署配置与文档都恢复 `direct`。
