# ADR 0011：活跃会话快照采集与数据库失联自恢复

- 状态：已采纳
- 日期：2026-08-25
- 契约版本：2.9.1

## 背景

Codex rollout 是会持续追加的 JSONL 文件。旧实现打开文件后在异步读取全过程持有 `BEGIN IMMEDIATE`，当活跃会话持续写入时，采集可能长期追逐文件尾部并占住 SQLite 写锁。其他连接随后无法更新飞书游标、条件跟踪、出站队列或心跳，进程虽然存在，数据面已经离线。

## 决策

1. 采集开始时固定文件 `stat.size`，只读取该快照范围。
2. 解析不持有写事务；证据和对应游标按最多 200 行的短事务原子提交。
3. 快照后的追加内容由下一轮增量采集处理。
4. 数据库心跳连续失败达到配置阈值时，子进程以非零状态退出，由既有监督进程自动重启。
5. 在线状态同时依据进程、数据库心跳和外部来源轮询，不以 PID 单独判断。

## 后果

采集不再因活跃会话持续增长而无限占锁；崩溃最多重放一个未提交小批次，证据指纹保证幂等。极端数据库故障会造成一次受控重启，但优于长期假在线。
