# ADR-0041 本地语音识别选型、分段与初始化任务

日期：2026-10-22。状态：已接受，按本决策接入；真实验收结果另列，不把设计当作已验证能力。

## 目标与边界

Fun-ASR-Nano 为首选本地识别器，SenseVoice 为兼容后备。自动选择依据是依赖、实际 CUDA/BF16 运算、资源余量和样本验收，不是仅看显卡型号或安装成功。仅有 CPU 时默认 SenseVoice，不静默让 Fun 以 CPU 慢速运行。用户可明确选用 SenseVoice。云端 API 是显式扩展，不是本地失败后的自动上传路径。

保留现有 Evidence、Collaboration、Work Session、Workboard 和知识维护队列，不新增语音主控或知识权威。录音是观察信息，不因声音像用户就成为执行授权。

## 音频与说话人边界

1. 录音发生时间加片段偏移用于跨飞书/语音排序；接收、识别时间仅用于调度。物理录音包、声纹片段、ASR 窗口和语义会话不是同一种边界。
2. 原音频先 VAD、提取声纹和聚类，再规划 ASR 窗口；不把重复的上下文音频再计入声纹或讲话时长。不跨已知的说话人切换边界；unknown 不表示同一个人。
3. 20～30 秒附近优先停顿，实际 ASR 输入（含边缘补音、重叠）硬上限 35 秒。无停顿时强制切开，后段最多回看 1 秒，且不得越过其说话人区间。短尾通过均衡前段边界避免，不丢弃真实短回答。
4. 当前 ASR 没有词级对齐。强制边界有重叠时同时保留上下文转写与不重叠核心转写；正式正文采用核心转写，重叠候选供 Agent 结合前后文复核。不能仅凭字符串相同就删除真实重复话语，也不能把候选另发一条 Evidence。今后验证词级对齐后可替换此保守策略。
5. 当前声纹是 VAD 片段聚类，不能检测片段内部换人或多人同时讲话；这项局限必须随结果保留，不能声称实现完整说话人分离。

## 引擎与失败处理

- 统一转写结果包含原录音范围、正文、说话人候选、模型/版本、原始识别尝试、边界候选及质量告警。更换 ASR 不改变录音身份和事件幂等键。
- Fun 使用独立 Python/CUDA 环境的本地子进程，单并发、同一录音内复用权重，结束关闭并释放。原有 CPU 环境不安装 torch，不修改系统驱动。
- 资源不足、依赖不满足时按运行配置降级 SenseVoice 或保留失败。未知 provider 是配置错误，不能伪装成已启用云端或成功降级。
- Fun在未触及时间/token上限但复读或异常空输出时，沿既有更短范围恢复/本地后备策略处理；更短Fun恢复共享原请求总截止，不重置预算。时间或token触顶且未正常结束时走部分结果保留，不能再自动恢复或转后备。失败尝试保留于私有回执；未解决的异常不得作为已完成转写入库。
- 2026-10-25新增：生成式ASR预算默认实际输入时长的2倍，`voice.asrTimeBudgetFactor`可配置1至10；模型冷加载排除，父进程监督和token边界停止共同约束。1倍原验收结果不被追认为2倍；用户已允许放宽以减少正常语音截断。时间上限不是幻觉或准确性检测。
- `partialResults`保留原文字、窗口范围、预算/倍率和停止原因，与完整segments分开。原音频和完整段不丢弃；部分结果不发Evidence、不冒充无人声、不触发自动重识别。重启后界面仍可读，人物标注不受影响。
- VAD后对ASR副本施加受峰值限制的有限增益，默认最多12dB；不开启检测前放大，声纹仍用原样本。低音量不等于静音，增益不等于改善信噪比。旧SenseVoice非生成式执行路径不新增硬截止；MOSS按下述扩展接入同一输入与保存链路。
- 质量筛查是异常检测，不是准确率保证。几秒一句的真实重复不能被简单的全局去重删除。SenseVoice 的非空文本同样不是正确性证明。
- API 扩展使用现有转写函数/带音频 SHA 的预计算包入口，仍走相同校验、幂等和更正流程；凭据在扩展的安全配置中，不进入 USER.md、卡片或 Git。

## 初始化与配置

用户选择“语音/录音”来源后，原有初始化任务计划添加一张 Agent 卡“配置并验收语音输入”，不要求用户先完成不必要的语音登录卡。卡内先询问录音来源、速度/质量偏好、是否允许云端，再检查资源、复用缓存或安装隔离运行环境、试跑并写回配置与回执。需登录或硬件条件时，在同卡等待输入并续接。未选择语音的用户不安装模型。

个人长期偏好归知识库；有效引擎、解释器、模型目录、资源余量和后备策略归版本化运行配置。不把运行路径复制成第二套个人事实，不由 USER.md 控制设备。初始化任务通过既有确认和幂等队列交给主 Agent 创建/推进卡片，不另设初始化调度器。

## 实施与验收

先完成纯函数分段测试，再接入真实 Fun 子进程与本地降级，最后走 CLI 导入到隔离库。检查：35 秒硬上限、同人长句、换人/unknown 边界、碎尾、声纹不重复、资源失败、复读/无 EOS、重试幂等、空库初始化和旧用户不重复初始化。真实长录音、抢话及专业词质量必须另留证明边界。

录音总时长与 35 秒识别窗口独立。长文件分块读取，但 VAD 状态跨读取块连续，声纹与 ASR 按原音频范围读取。不能把十分钟/一小时的旧单文件限制当 ASR 模型上限，也不能一次展开数小时音频。物理包分窗时若标签仅在窗口内有效，必须保留其作用域，不假装全文件同名标签就是同一人。

不在本次修改运行中的旧采集程序、不启动麦克风、不将测试音频或测试结论写入正式知识库。新入口验证后可供主 Agent 与采集交付调用；是否已自动接上到达通知应独立报告。

## MOSS扩展（2026-10-25）

用户接受已实测短讨论的MOSS联合转写/人物分离结果，决定接入本机共用入口。显式`moss-local`需要已有独立CUDA/BF16环境及核验模型、上游工具目录；不自动安装、无隐式云端或Fun后备，现有auto-local选择逻辑不变。

本扩展仅对MOSS替换前述音频边界第2、3、5项：VAD先筛出语音，随后把若干轮对话放入有限窗口，由MOSS返回局部说话人及文字，再提取原音频干净范围声纹。单次默认60秒，允许配置5至120秒，补音和最多1秒强制边界上下文都计入。短停顿不拆成独立调用，VAD最大长度产生的人工切点不当成真实停顿。完整输出仅意味着协议完成，不意味着文字、重叠分离或人物身份已经人工确认。

物理分片、VAD帧和MOSS窗口独立：intake沿既有流式磁盘组装保留分片出处；ASR在原时间轴有界读取并连续传递VAD状态。MOSS窗口标签必须同时携带声学作用域，复用已有跨作用域匹配能力；同一窗口的不同标签仍不得自动折叠。

新失败原因与时间/token触顶同样保存为部分结果，不覆盖前面已完成片段。Windows父进程结束要核对原生子解释器，不能把启动器退出当作GPU工作停止。接入、入库、界面与资源控制分别留测试证据，见共用入口报告；正式后台与历史标注保持不动。
