# ADR-0027 有界摘要与正交知识状态

- 状态：接受
- 日期：2026-09-02
- 决策者：项目用户、Codex
- 关联契约：INV-60、INV-61、INV-69、INV-70、INV-71、INV-72

## 背景

Codex 会话的每条工具结果都会刷新摘要签名，导致同一长任务反复重建全部分块。旧代只建立 `supersedes` 链而不清理，数百次重建后形成大量重复摘要和 FTS 记录。

知识侧同时把 `linked` 当作处理结果和可信提示，把 `needs_review` 混入事实可信状态，并允许多个入口直接指定状态或无约束关闭旧事实。这让“处理完了、事实有效、证据强、旧事实失效”四件事互相污染。

## 决定

1. Codex 用户输入和回合完成信号可立即触发摘要；连续助手和工具流水等待 120 秒安静期后兜底处理。
2. 每个 Codex 会话只保留当前一代可检索摘要。被长期事实直接引用的旧摘要降为不可检索归档证据，其余旧代删除；原始 Evidence 和 rollout 不删除。
3. Episode 复核状态固定为 `pending/completed/needs_input`，完成结果固定为 `facts_recorded/no_durable_facts`。
4. Fact 生命周期固定为 `active/superseded`，证据立场固定为 `supports/contradicts`，Fact 可信状态固定为 `proposed/supported/disputed/refuted`。
5. 可信状态由当前未失效证据和开放冲突集中推导。`verified` 只允许作为查询展示分组，`needs_review` 只允许作为维护元数据，`mentions` 只允许作为实体证据关系。
6. 业务实体和谓词保持开放；维护协议只保留 `supersedes`。事实取代必须同主体、同谓词、同作用域，并具备来源、理由、无自指和无环。失败时保留新旧事实并进入人工复核。
7. 主服务与 OpenClaw 插件共用 `src/knowledge-policy.mjs`，不得复制一套相似规则。

## 影响

- 摘要写放大和 FTS 体积不再随工具调用次数线性增长。
- 事实引用的历史摘要仍可审计，但不会参与普通全文召回。
- Episode “已处理”不再被误读为事实可信。
- 错误修订不会丢弃新信息，也不会静默关闭不同主体或范围的旧事实。
- 领域关系数量不受维护协议收敛影响，图谱仍可表达人员、项目、版本、代码、文档和流程。

## 迁移

`scripts/migrate-knowledge-state-and-digests.mjs` 默认只读审计；`--apply` 先在线备份 SQLite，再迁移复核列、清理旧摘要、转换非法 `mentions` 评价并重算活动事实可信状态。`--compact` 在迁移后回收空闲页。迁移报告与备份保存在同一目录。

## 验证

- 安静期、即时信号、单快照和事实引用归档均有单元测试。
- 弱支持、直接支持、矛盾、非法 `mentions`、安全取代和跨主体误取代均有单元测试。
- 迁移前后执行 `PRAGMA quick_check`，并对真实库记录摘要代数、可信状态和复核状态分布。
