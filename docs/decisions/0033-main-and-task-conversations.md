# ADR-0033 主对话与独立任务会话

- 状态：接受；实现与隔离验证见本次变更，生产运行验证另行记录
- 日期：2026-10-15
- 部分取代：ADR-0013、ADR-0014、ADR-0019 中任务复用来源/人工会话的归属规则

## 产品目标

用户有一个长期主对话入口，用来讨论、交代新工作和询问总体进展；需要持续推进的工作进入 Workboard。任务列表中的卡片是任务会话入口，不是另一个 Agent。进入任务后能看到连续交代、答复和结果，底部常驻输入框；不再反复弹出“继续交代”遮罩。

首页只有“主对话 / 工作”两种视图，不按问答、知识、提醒拆输入模式。工作视图保留“需要你处理 / Agent 负责 / 最近完成”，内部条件跟踪仍为只读投影；提醒和外发审核继续保留独立可靠交付语义。角标进入待办，双击宠物展开当前视图，X 仍只隐藏，托盘退出才停止整套服务。

## 上下文边界

1. 主对话固定使用 `agent:main:shadow:user`，不是按消息或日期重建。保存原话、完整最终答复和任务链接；聊天列表按页读取已有回执与 Evidence，不再复制一份 transcript。
2. 每张卡通过 `shadow-task + card_id` 绑定稳定 `session_kind=task`。主对话、任务 A、任务 B 的 session key 均不相同；关闭窗口、重启和继续交代不改变任务身份。
3. 卡片创建/续接由主控语义决定。主对话必须在卡中留下本次 Evidence ID，只回复简要交接结果，不在主对话开展长工程执行。可靠回执处理器将关联卡绑定独立会话，并用幂等的 `task_handoff` 操作投递这次交代。
4. 任务会话首先读取当前卡和本次证据，只按需查询共享知识、来源会话或其他任务。注意力包只提供绑定卡，不自动注入同项目的其他卡。相关来源是引用，不是历史全文复制。
5. 任务回复写回同一卡的 Workboard 评论或结果检查点，界面对操作、评论和检查点做只读时间线投影。没有回执时显示等待，不伪造 Agent 答复。主对话不自动接收任务执行流水；用户通过链接进入任务，询问总体进展时由主控有界查询摘要。
6. 只有一个 OpenClaw 语义主控；多个会话是上下文边界，不是多个决策中心，不提高并发。Workboard 仍是唯一任务状态，原生 Codex child execution 字段不被覆盖。
7. 人工交代、修正、完成确认仍进入原有 Episode、可靠事件和知识维护通路；不增加另一套知识写入协议。
8. 窗口折叠/隐藏时不刷新聊天记录。可见任务只轮询有界对话投影和标题状态，不反复加载完整证据、知识处理和执行详情；阅读历史时保留滚动位置。

## 迁移与故障处理

- 不清理旧历史、不复制旧主对话，不修改个人 Codex 数据；新任务直接采用独立会话。
- 旧卡在首次人工操作或进度监督时按稳定 card_id 重绑。只重路由精确 taskId 的 pending 事件、未结束跟踪及未领取 Workboard 操作。已领取/运行中的事件完成原轮后再切换，不能抢走其租约或新开重复工程任务。
- 原始来源、证据 ID、卡 ID 和原生执行会话保持不变。无 taskId 的外部聊天仍在来源会话中作语义判断，不能将整个群或主对话迁移给一个任务。
- 输入关闭窗口仍保存；离线沿用可靠 outbox。不同卡的未发送草稿在当前界面进程内分开保存，刷新不会覆盖草稿；未发送草稿不承诺跨应用重启保存。
- 本次不自动启动生产 Agent、不发送消息、不消耗真实模型轮次进行业务推进。上线应先停止服务、备份运行库，再更新插件/工作区并启动；不要在旧主控运行中热切换归属。

## 验收

- 主对话连续问答、任务链接、历史翻页、Markdown 安全渲染、离线回执及窗口重载恢复。
- 同一主对话交代两项工作，产生不同稳定任务会话；跟进只投递目标任务，重启后身份不变。
- 旧卡精确迁移、不挪动其他任务/背景事件、不修改原生 Codex 执行标识、不抢运行租约。
- 独立任务注意力包不带其他任务，任务答复和检查点能展示。
- Playwright/Electron 隔离数据库测试主对话跳转、任务持续输入、切换草稿、异步回包防串、窄/高窗口点击命中与截图；没有生产发送或真实设备动作。
