# 动作风险策略

| 风险 | 示例 | 第一版行为 |
|---|---|---|
| `read` | 读文件、查历史、分析代码、检查状态 | 自动执行 |
| `local-write` | 修改代码、生成正式本地文档、运行会产生输出的测试 | 建立任务，等待确认或白名单 |
| `external-write` | 回复飞书、编辑远程文档、更新多维表格 | 等待确认 |
| `approval-decision` | 同意、拒绝、转交审批 | 等待确认 |
| `destructive` | 删除、覆盖、撤回、权限变更 | 始终人工确认 |
| `external-auth` | 飞书、语雀等用户授权 | 等待用户完成授权 |

低风险并不代表可以忽略证据。自动任务必须保存输入证据、Codex任务ID、结果和验证状态。
